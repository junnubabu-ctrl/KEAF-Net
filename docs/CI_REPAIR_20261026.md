## Failure and repair

The previous GitHub Actions workflow ran
`conda env update --file environment.yml --name base`, but this source tree
has no `environment.yml`. The latest recorded run failed at dependency
installation; lint and tests did not execute in that run.

The revised workflow installs the actual Python package with pip and an
explicit CPU-only PyTorch 2.14.1 runtime on Python 3.12. It tests two separate
packages in independent matrix jobs: `KEAF-Net-code/` is the corrected Paper 3
implementation; the repository-root `src/` package is a separate reference.
Both expose the same import name, so they must not be collected or installed
together in one CI environment. Legacy source directories and historical
verification records remain intact.

Each job checks dependency consistency, syntax and undefined names, and its
own test suite. The corrected job also executes its synthetic gradient and
optimizer probe and checks training/evaluation command entry points. The root
job executes its tensor smoke test. JUnit records, a corrected-source probe
record and the installed package versions are retained as CI artifacts, not
written over the historical `verification/` files.
