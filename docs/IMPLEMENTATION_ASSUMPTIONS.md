# Implementation Assumptions and Verification Log

This file is the mandatory audit trail for implementation choices that cannot be verified directly from the KEAF-Net manuscript, supplementary material, released code, or authoritative dependency documentation.

## Rules

For every ambiguous technical detail, record:

| Item | Evidence/source | Implemented choice | Status | How to verify |
|---|---|---|---|---|
| Example | Paper does not specify optimizer epsilon | configurable default, no claim of paper fidelity | ASSUMPTION | compare with authors' training configuration |

Status values:
- `VERIFIED` — directly supported by authoritative evidence.
- `ASSUMPTION` — reasonable engineering choice, configurable and not represented as exact paper behavior.
- `TODO-VERIFY` — implementation should not be used for a fidelity claim until checked.

## Experimental integrity

Do not report manuscript metrics as reproduced results unless they are generated by this repository under a documented configuration and retained evaluation output. Reference numbers from a manuscript must be labelled as reference/target values.
